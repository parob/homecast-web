Tab bar — every label visible

Every option below shows all five labels at once. Each is drawn at 320px (iPhone SE) and 390px (iPhone 14/15) against the real geometry — 5 pins max, the real glass, the real 64px slots. A red OVERFLOW flag appears if the tabs escape the bar's background, which is the bug that took the bar off the side of the screen.

What actually constrains this.
  • Five pins is the maximum, and the user chose each one — so they already know roughly what they are.
  • Names come from Apple Home and are not editable there: "Ensuite Underfloor Heating" is a real accessory name.
  • A tab can be renamed in Edit Layout, so a long name is fixable by hand — but the default has to be survivable.
  • The bar sits in the thumb zone at the bottom edge; 44px is the minimum comfortable target.
