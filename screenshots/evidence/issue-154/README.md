# Camera tile sizes — Regular, Large and Tall

Evidence for parob/homecast-cloud#154: a camera tile that can take four cells
(Large, 2×2) or two stacked ones (Tall, 1×2), and the control for choosing.

Regenerated by `widget-sizes.spec.ts`, which measures the same geometry it
photographs — the pictures and the assertions come from one run, so they cannot
disagree. Committed for the reason `issue-118/README.md` gives: a pull request
whose substance is "is the picture bigger" has to show the picture in the pull
request, and only images served from a GitHub host embed.

| File | What it shows |
|---|---|
| `widget-size-regular.png` | Before — a landscape camera at 1×1, picture mostly cropped away |
| `widget-size-large.png` | After — the same camera at Large: full width, 16:9, nearly uncropped |
| `widget-size-regular-portrait.png` | Before — a portrait camera at 1×1 |
| `widget-size-tall.png` | After — the same camera at Tall: one column, two rows |
| `widget-size-menu.png` | The desktop context menu: Size → Regular / ✓ Large / Tall |

The picture in the fixture is drawn on a canvas, not a real camera: no private
camera photograph belongs in a repository. The red corner marks are there so a
crop is obvious at a glance: at Regular none of them survive the crop, and at
Large the top pair is back in frame.
